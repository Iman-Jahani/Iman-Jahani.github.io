# پنل مدیریت کلاس‌های پایتون 🔐

## دسترسی به پنل

برای دسترسی به پنل مدیریت، فایل `admin.html` را باز کنید.

**آدرس:** `https://iman-jahani.github.io/admin.html`

## رمز ورود

```
admin2025
```

## امکانات پنل مدیریت

### 📊 داشبورد اصلی
- **تعداد کلاس‌ها**: نمایش تعداد کل کلاس‌های ایجاد شده
- **تعداد تیم‌ها**: نمایش تعداد کل تیم‌های فعال
- **تعداد کدها**: نمایش تعداد کل سلول‌های کد نوشته شده
- **تعداد کامنت‌ها**: نمایش تعداد کل کامنت‌های ثبت شده

### 📚 بخش کلاس‌ها
برای هر کلاس نمایش می‌دهد:
- نام کلاس
- کد کلاس (برای اشتراک با دانشجوها)
- تاریخ ایجاد
- تعداد تیم‌های عضو
- تعداد کدهای نوشته شده

### 👥 بخش تیم‌ها
برای هر تیم نمایش می‌دهد:
- نام تیم
- رنگ تیم
- نام کلاس متعلق به آن
- تعداد اعضای تیم
- تعداد کدهای نوشته شده

## ویژگی‌ها

✅ **امنیت**: نیاز به رمز عبور برای دسترسی  
✅ **به‌روزرسانی زنده**: دکمه refresh برای دریافت آخرین داده‌ها  
✅ **رابط کاربری تیره**: طراحی مدرن با تم تیره  
✅ **نمایش زمان**: نمایش زمان آخرین به‌روزرسانی  
✅ **ریسپانسیو**: قابل استفاده در موبایل و دسکتاپ  

## تغییر رمز عبور

برای تغییر رمز عبور، خط زیر را در فایل `admin.html` ویرایش کنید:

```javascript
const ADMIN_PASSWORD = 'admin2025'; // رمز عبور فعلی
```

## نکات امنیتی

⚠️ **مهم**: این رمز عبور در کد جاوااسکریپت قرار دارد و از نظر امنیتی کامل نیست.  
💡 **توصیه**: برای استفاده در محیط واقعی، از سیستم احراز هویت سرور-ساید استفاده کنید.

## پشتیبانی

در صورت بروز مشکل، از اطلاعات زیر استفاده کنید:

- Tables: sessions, teams, cells, comments
